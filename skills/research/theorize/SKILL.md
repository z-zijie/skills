# 理论化

归纳，不是流水账。终点是一个能生成新预测的最小机制模型，外加回灌给 hypothesize 的候选预测。

## 1. 证据分级

过一遍台账，每行归入三态：

- **已证**：delta 超噪声底 + 门绿 + vet 为 VERIFIED。
- **已驳**：方向相反，或"无差异"成立。
- **未决**：INCONCLUSIVE、crash、样本不足。

负结果与 near-miss 都是模型输入，不许丢：已驳的假设省得重跑，near-miss 是组合原料。

## 2. 最小模型

- 用已证证据拼最小机制模型：什么、通过什么途径、影响什么。一句话能说清。
- **简洁性判据**：两个模型解释力相同，取简单的；删掉一个环节模型不变，那个环节不承重，删。
- 模型必须能回答："下一轮改 X 会怎样？"答不出的不是模型，是摘要。
- **落盘为先验** `model.md`：最小模型 + 已证 / 已驳清单 + 未测预测。质量门：只收过三态裁决的——已证给方向，已驳防重测；未决留在台账，不进先验。

## 3. 出预测

至少一条**未测**预测，写成机制句追加进候选池（`candidates.md`）：

- 模型说该有效而没试过的；
- 模型说该无效的（反向验证，防自欺）。

## 4. 平台期协议

连续多轮（约 5 轮）keep 不了即进入平台期，按序尝试：

1. 换类别：一直在调参数，就换结构、换数据、换指标口径。
2. 组合台账里的 near-miss。
3. 回 survey 重读"可借方法""矛盾证据"。
4. 更激进：当作这个需求第一天就存在，重新设计，而不是打补丁。

卡死是合法状态：写明卡在哪、试过什么，交回，不原地空转。

完成判据，逐项核对：

- [ ] 台账每行有归级（已证 / 已驳 / 未决）
- [ ] 先验 `model.md` 落盘（模型 + 已证 / 已驳 + 未测预测），一句话能说清
- [ ] 至少 1 条未测预测进候选池
