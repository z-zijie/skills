# 立题

把"研究一下 X"变成一句可判真假的谓词。研究循环的每个环节都锚在这句谓词上：谓词模糊，后面全是空转。终点是一张落盘的研究卡，接手者免采访即可开工。

## 1. 采访对齐

一次问全，每项要么有答案、要么"未知"：

| 问什么 | 要什么 |
| --- | --- |
| 研究问题 | 一句话：X 对 Y 的效应 / 机制 / 最优配置 |
| 完成谓词 | 什么观测结果算"已回答"，可判 true/false |
| 指标意向 | 关心什么数字，哪个方向算好 |
| 预算 | 时间、算力、并发、花费、轮数上限 |
| 范围 | in-scope 清单（文件 / 模块 / 系统），以及明确不碰什么 |
| 研究类型 | 复现型（复现已知结果）/ 探索型（开放优化）/ 判定型（A vs B 择优） |

完成判据：谓词写成一句话，任何人数月后读到能判 true/false。写不出这句话就回到提问；猜出来的谓词锚死后面所有工作。

## 2. 停止规则草案

谓词配停止规则，形状固定：**目标 + 尝试次数下限**。

- 下限防"运气好提前收工"：一次惊喜命中不算回答（例："比基线好至少 50%，且跑满 10 轮"）。
- 预算上限防无限空转：轮数 / 时间 / 花费到顶即收尾，未决项如实交付。

## 3. 落盘研究卡

写入研究工作目录的 `research.md`（用户指定优先）：

- 问题一句话（用户原话 + 提炼版）
- 完成谓词与停止规则
- 范围表：`条目 | in/out | 说明`
- 预算
- 研究类型与初始指标意向（供 harness 细化）

完成判据，逐项核对：

- [ ] 谓词一句话可判真伪
- [ ] 停止规则含次数下限与预算上限
- [ ] 范围表区分 in/out
- [ ] 研究卡落盘，接手者凭它可开工

## 判不出去

意愿提炼不出可证伪谓词（如"让模型变好"且拒绝任何指标）时，如实说明并停在这一步：没有谓词的循环不是研究，是漫游。
