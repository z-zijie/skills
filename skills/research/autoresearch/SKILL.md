# 自主研究

你在运营一个小型研究程序，不是替人跑一轮实验。人给目标与预算，你跑循环。流程由十个纪律 skill 承载，本 skill 只做编排与政策。

## 开工（顺序不可换）

1. **question** 立题：研究卡落盘（谓词、范围、预算、停止规则）。
2. **survey** 调研：后台 agent 跑长阅读，主线程收四栏纪要。
3. **harness** 基建：指标、测量、噪声底、冻结、基线、回归门。冻结之前不进循环。
4. **logbook** 初始化：表头 + 基线行。

## 循环

```
LOOP:
  hypothesize   候选池排序，入选者预注册（串行 1 条 / 并行 N 条）
  experiment    一改一测，跑完补行（并行时一假设一 worktree）
  vet           裁决三态 → keep / discard / crash
  theorize      每跑完一批（约 5-10 轮）或进入平台期时进
UNTIL 停止谓词满足 或 预算耗尽
```

## 并行档位

预算允许时，每轮从候选池放 N 条独立假设并行验证：

- N 由预算的并发上限定（几个 worktree、几张卡、多少并发额度），默认 1 即串行。
- 只有互相独立的假设并行；会碰同一份状态的串行。
- 一假设一 worktree，台账各记一行，裁决各自独立。
- best-of-N 的胜者含选择偏置（赢家诅咒），过 vet 复跑确认后才 keep。

## 工具化经济

隔夜自主跑里，只有工具复利，手工不复利：

- 同一手工动作第三次出现（第一遍学，第二遍确认），按 create-tool 造工具，别再付第四遍。
- 工具落在研究目录、随 run 提交：它和台账一样是研究产出，评审者能重跑。
- 测量工具归 harness 冻结；抽取、比对、汇总类工具随用随造。

## 停止谓词

question 立的形状：目标 + 尝试次数下限。

- 不许为收工放松谓词；
- 便宜且未试的假设还有，就不许退；
- 谓词满足才进收尾；预算耗尽也进收尾，未决项如实交付。

## 自主性政策

- 可逆操作直接做，回头汇报；不问"要不要继续"。
- **暂停清单**（不可逆才问人）：删数据、超预算的花费、动共享或生产资源。
- "我睡了 / don't stop / 跑到完" = **NEVER STOP**：不问"是不是该停了"。没想法时按序自救：重读 survey 两栏 → 组合台账 near-miss → theorize 出新预测 → 更激进的重设计。
- 台账 + git 是完整状态：随时可暂停、可恢复、可交接，不依赖对话历史。

## 上下文管理

- 主上下文只进 grep 出的关键行与台账；
- survey 等长阅读走后台 agent，只收纪要；
- 跨轮记忆只有台账，不指望对话上下文活着。

## 收尾

1. **report** 成文：证据分级、复现指令。
2. **reflect** 复盘：教训编码回 skill / 门 / 脚本。

## 汇报格式

阶段汇报与最终汇报同构：当前指标 vs 基线、轮数（keep / discard / crash 各几）、最近一条 keep 一句话、下一步假设、台账路径。
